[color=#D9A441][size=5]Mr. Prepper - Български превод[/size][/color]

[color=#D9A441][size=4][b]Какво съдържа модът:[/b][/size][/color]
[color=#E7E2D3]Това е български превод на интерфейса и текстовете в [b]Mr. Prepper[/b]. Преводът се зарежда автоматично при стартиране на играта. Модът е наличен за изтегляне чрез GitHub и може да служи като основа за други локализации.[/color]
[list]
[*][color=#E7E2D3]Преведени са основните менюта, настройките, контролите и подсказките.[/color][/*]
[*][color=#E7E2D3]Преведени са голяма част от диалозите, предметите, задачите, уроците и описанията.[/color][/*]
[*][color=#E7E2D3]Запазени са променливите, цветните тагове, новите редове и специалното форматиране на играта.[/color][/*]
[*][color=#E7E2D3]Добавена е поддръжка за текстове, които играта зарежда динамично.[/color][/*]
[/list]
[color=#E7E2D3]Преводът е в активна разработка. Възможно е отделни редове да останат на английски, да са прекалено дълги или да изискват допълнителна редакция според конкретния екран.[/color]

[line]
[color=#d9a441][size=5]Mr. Prepper - Bulgarian Translation[/size][/color]

[color=#D9A441][size=4][b]What this mod contains:[/b][/size][/color]
[color=#E7E2D3]This is a Bulgarian localization for the interface and text of [b]Mr. Prepper[/b]. The translation is loaded automatically when the game starts. The mod will be available on GitHub and can be used as a base for other localizations.[/color]
[list]
[*][color=#E7E2D3]Main menus, settings, controls, and tooltips are translated.[/color][/*]
[*][color=#E7E2D3]A large part of the dialogue, items, quests, tutorials, and descriptions is translated.[/color][/*]
[*][color=#E7E2D3]Placeholders, color tags, line breaks, and the game's special formatting are preserved.[/color][/*]
[*][color=#E7E2D3]Text loaded dynamically by the game is supported where possible.[/color][/*]
[/list]
[color=#e7e2d3]The translation is actively maintained. A few lines may still remain in English, be too long for a particular UI element, or need additional editing after in-game review.[/color]

[color=#D9A441][size=4][b]Requirements[/b][/size][/color]
[list]
[*][color=#E7E2D3][url=https://store.steampowered.com/app/761830/Mr_Prepper/][b]Mr. Prepper[/b][/url][/color][/*]
[*][color=#E7E2D3][b][url=https://github.com/bepinex/bepinex/releases]BepInEx 5.x Mono[/url][/b] installed in the game directory, tested and working with [b]v5.4.23.5.[/b][/color][/*]
[/list]

[color=#D9A441][size=4][b]Installation[/b][/size][/color]
[list=1]
[*][color=#E7E2D3]Download the mod ZIP archive.[/color][/*]
[*][color=#E7E2D3]Extract it into the game directory so that the[/color]
[code]BepInEx[/code]
[color=#E7E2D3]folder is merged with the existing folder.[/color][/*]
[*][color=#E7E2D3]Launch the game. The translation is loaded automatically.[/color][/*]
[/list]
[b][color=#d9a441][size=4]Configuration and diagnostics[/size][/color][/b]
[color=#E7E2D3]Translation is enabled by default. Diagnostic options are not required for normal gameplay. If you want to collect text or inspect another language for reference, they can be changed in:[/color]
[code]BepInEx/config/actepukc.mrprepper.uitranslationbulgarian.cfg[/code]
